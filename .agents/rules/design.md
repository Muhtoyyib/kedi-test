# Design Rules

Full system: `docs/design-system.md`.

- Palette is derived from KEDI's identity: KEDI Blue (`brand`), KEDI Sun yellow (`sun`), Navy (`ink`), Leaf green (`leaf`). Use the semantic tokens, not the base colours.
- Yellow is a background/highlight colour only. Never yellow text on white.
- WhatsApp actions always use the `whatsapp` button variant (WhatsApp green with dark text and the WhatsApp glyph), so visitors recognise them instantly.
- One primary action per section. Secondary actions are `outline` or text links.
- Light theme only.
- Real photography of the distributor, customers and packshots. No AI-generated people. No stock "doctor with stethoscope" imagery.
- Mobile first: single column at 360px, 16px side padding, body text 16px minimum.
