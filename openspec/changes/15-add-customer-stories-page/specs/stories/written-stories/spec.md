## Purpose

Lists every written customer story, featured ones first, with the option to read the longer version.

## ADDED Requirements

### Requirement: All written stories

The page SHALL list every published written story, featured stories first then newest, each showing the quote, first name and initial, area, and the longer story when provided.

#### Scenario: Long story

- **WHEN** a story has a longer body
- **THEN** the card shows the beginning with "Read full story", which expands the full text
