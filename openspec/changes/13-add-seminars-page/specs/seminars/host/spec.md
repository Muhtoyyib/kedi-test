## Purpose

Introduces the seminar host with a photo and short biography so visitors know who they will meet.

## ADDED Requirements

### Requirement: Host introduction

The section SHALL show the host's photo, name, role as an independent KEDI distributor in the city, a short biography, and a WhatsApp action addressed to the host by first name.

#### Scenario: Host section

- **WHEN** a visitor views the host section
- **THEN** they see the host's photo, name, role and bio, and a "Chat with {first name} on WhatsApp" button
