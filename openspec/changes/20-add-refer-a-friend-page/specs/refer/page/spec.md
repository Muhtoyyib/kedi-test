## Purpose

Defines the Refer a Friend page: explaining the reward, generating a personal link instantly, and sharing it.

## ADDED Requirements

### Requirement: Refer page flow

/refer SHALL explain the reward, show how it works, let a customer get their personal code and link, offer sharing options, and state the terms.

#### Scenario: Returning referrer

- **WHEN** a customer who generated a code last week opens /refer on the same phone
- **THEN** their code and share options are shown without re-entering details
